How to read this book: choose chapters from the index below by their description and size, and read only those. In a local build (`target/docs/html/`) each linked file also sits beside this one and matches the checkout; the site follows `main`, which can be ahead of the release in use (`kb-mcp --version`).

To use kb-mcp from an agent, read MCP Server and Tools. To set it up for a project, read Configuration. Why kb-mcp exists and how it compares with other projects is a separate book, with its own `llms.txt` under `product/`.
